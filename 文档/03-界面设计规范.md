# 03-界面设计规范

> 版本：v1.0 ｜ 2026-08-13 ｜ 状态：已定稿
> 风格关键词：**清新极简**。写任何页面样式前先读本文档。

## 1. 设计原则

1. **留白优先**：内容密度低，宁可有呼吸感，不要堆砌
2. **信息分层**：一眼先看到"结论"，再看到"数据"，最后是"解释"
3. **少即是多**：一个页面只讲一件事；不用复杂动效、不用装饰性元素
4. **为小白设计**：每个指标都有通俗解释；结论用大色块徽章，一眼看懂

## 2. 配色（全站唯一色板，禁止引入其他颜色）

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#F7FAF8` | 近白，带一丝绿意的暖白 |
| 卡片/内容背景 | `#FFFFFF` | 纯白 |
| 主色（品牌绿） | `#2E9E6B` | 用于按钮、链接、"值得买入"徽章 |
| 主色浅底 | `#E8F5EE` | 徽章/标签的浅色底 |
| 警示黄 | `#D9A13B` | "可分批买入"徽章（底 `#FBF3E2`） |
| 中性灰 | `#8A9490` | "暂不建议买入"徽章（底 `#EFF2F0`） |
| 下跌红 | `#D9544D` | 仅用于下跌数字（底 `#FBEBEA`） |
| 标题文字 | `#1F2A25` | 深墨绿灰，不刺眼 |
| 正文文字 | `#3D4A44` | 次级文字 `#8A9490` |

规则：**绿色=机会，黄色=谨慎，灰色=观望，红色只表示下跌**，四种语义色不混用。

## 3. 字体与排版

- 字体栈：`-apple-system, "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`（系统字体，不引外部字体）
- 字号：页面标题 28px / 区块标题 20px / 卡片标题 17px / 正文 15px / 辅助说明 13px
- 行高：正文 1.7；数字用等宽数字字体特性 `font-variant-numeric: tabular-nums`
- 全部用 flex/grid 布局，卡片间距 16px，页面最大宽度 1080px 居中

## 4. 组件规范

### 4.1 股票卡片（首页）
- 白底卡片，圆角 12px，阴影 `0 1px 3px rgba(31,42,37,.06)`，hover 轻微上浮（translateY -2px，不做其他动效）
- 结构自上而下：行业标签 + 股票名（大字）+ 代码（灰色小字）→ 结论徽章（大，占视觉主体）→ 关键指标行（PE 分位 / ROE / 股息率，2~3 个）→ "查看详情 →" 链接
- 整张卡片可点击进入详情页

### 4.2 结论徽章（全站统一）
- ✅ 值得买入：绿字 `#2E9E6B` + 浅绿底 `#E8F5EE`，圆角胶囊
- 🟡 可以买入，建议分批：黄字 `#D9A13B` + 浅黄底 `#FBF3E2`
- ⚪ 暂不建议买入：灰字 `#8A9490` + 浅灰底 `#EFF2F0`
- 徽章旁小字注明主要依据（如"PE 处于近 5 年 18% 分位"）

### 4.3 指标块（详情页）
- 网格布局，每格一个指标：数值（大字）+ 指标名（小字）+ 通俗解释（13px 灰色，最多一行）
- 指标按五组分区：估值 / 盈利 / 成长 / 健康 / 技术

### 4.4 免责声明横幅
- 页面顶部固定浅灰绿底 `#EFF5F1` 细横幅，13px 灰字，全文：
  "本网站内容仅供学习参考，不构成投资建议。股市有风险，投资需谨慎。"

## 5. 页面布局规范

| 页面 | 布局 |
|---|---|
| base.html | 顶部：站名（左）+ 导航（首页/历史/方法论）+ 免责横幅 |
| 首页 | 标题"今日精选" + 推荐日期 → 3 张股票卡片横排 → 底部小字链接"为什么是这 3 只？（看筛选逻辑）" |
| 个股页 | 顶部概览条（名称/代码/现价/涨跌/行业/市值）→ 结论卡片（徽章 + 依据 + 参考价位区间 + 免责）→ 五组指标网格 |
| 历史页 | 按日期倒序的日期分组列表，每只股票一行：名称、当时结论徽章、推荐日、推荐后涨跌幅（绿涨红跌，与全站"绿=机会/红=风险"语义一致） |
| 方法论页 | 文章式排版：筛选流程五步，每步一段通俗解释 + 指标名词表 |

## 6. 响应式（移动端可用）

- 断点 768px：股票卡片由横排 3 列改为纵向堆叠；指标网格由 4 列改为 2 列；导航保持单行
- 触控目标不小于 44px

## 7. 禁止事项

- ❌ 不使用图片装饰、渐变背景、大面积色块
- ❌ 不使用前端框架/CDN 外部资源（本地运行，不依赖外网）
- ❌ 不使用动画库；唯一允许的动效是卡片 hover 上浮 2px
- ❌ 不展示超过 4 种语义色同屏
