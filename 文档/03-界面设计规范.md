# 03-界面设计规范

> 版本：v1.2 ｜ 2026-08-17 ｜ 状态：已定稿
> 风格关键词：**清新极简 · 莫兰迪色系**。写任何页面样式前先读本文档。
> v1.1 变更：配色由绿色系改为**莫兰迪色系**（雾蓝 + 砖红 + 沙金），并符合 A 股"**红涨绿跌**"惯例——红色表示机会/上涨，绿色仅表示下跌。
> v1.2 变更：新增 §4.5 公司介绍模块（对应 01 规范 F8）。

## 1. 设计原则

1. **留白优先**：内容密度低，宁可有呼吸感，不要堆砌
2. **信息分层**：一眼先看到"结论"，再看到"数据"，最后是"解释"
3. **少即是多**：一个页面只讲一件事；不用复杂动效、不用装饰性元素
4. **为小白设计**：每个指标都有通俗解释；结论用大色块徽章，一眼看懂

## 2. 配色（全站唯一色板，禁止引入其他颜色）

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#F7F6F2` | 米白（莫兰迪基调，无绿意） |
| 卡片/内容背景 | `#FFFFFF` | 纯白 |
| 主色（莫兰迪雾蓝） | `#5B7A9D` | 用于站名、按钮、链接、导航选中态 |
| 主色浅底 | `#EAF0F6` | 主色徽章/标签的浅色底 |
| 买入红（莫兰迪砖红） | `#B3564F` | "值得买入"徽章、上涨数字（底 `#F6E8E6`） |
| 谨慎沙金 | `#C29A5B` | "建议分批买入"徽章（底 `#F7F0E1`） |
| 中性灰 | `#929AA0` | "暂不建议买入"徽章（底 `#EFF0EC`） |
| 下跌绿（莫兰迪灰绿） | `#7A9E7E` | 仅用于下跌数字（底 `#EDF3EE`） |
| 标题文字 | `#2B3440` | 深蓝灰，不刺眼 |
| 正文文字 | `#46525C` | 次级文字 `#929AA0` |
| 免责横幅底 | `#EEF2F6` | 顶部免责声明细横幅底色 |

规则（符合 A 股惯例，红涨绿跌）：**红色=机会/上涨，蓝色=品牌/链接，沙金=谨慎，灰色=观望，绿色只表示下跌**，五种语义色不混用。

## 3. 字体与排版

- 字体栈：`-apple-system, "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`（系统字体，不引外部字体）
- 字号：页面标题 28px / 区块标题 20px / 卡片标题 17px / 正文 15px / 辅助说明 13px
- 行高：正文 1.7；数字用等宽数字字体特性 `font-variant-numeric: tabular-nums`
- 全部用 flex/grid 布局，卡片间距 16px，页面最大宽度 1080px 居中

## 4. 组件规范

### 4.1 股票卡片（首页）
- 白底卡片，圆角 12px，阴影 `0 1px 3px rgba(31,42,37,.06)`，hover 轻微上浮（translateY -2px，不做其他动效）
- 结构自上而下：行业标签 + 股票名（大字）+ 代码（灰色小字）→ 结论徽章（大，占视觉主体）→ 关键指标行（PE 分位 / ROE / 股息率，2~3 个）→ "查看详情 →" 链接
- 整张卡片可点击进入详情页

### 4.2 结论徽章（全站统一）
- ✅ 值得买入：红字 `#B3564F` + 浅红底 `#F6E8E6`，圆角胶囊
- 🟡 可以买入，建议分批：沙金字 `#C29A5B` + 浅沙金底 `#F7F0E1`
- ⚪ 暂不建议买入：灰字 `#929AA0` + 浅灰底 `#EFF0EC`
- 徽章旁小字注明主要依据（如"PE 处于近 5 年 18% 分位"）

### 4.3 指标块（详情页）
- 网格布局，每格一个指标：数值（大字）+ 指标名（小字）+ 通俗解释（13px 灰色，最多一行）
- 指标按五组分区：估值 / 盈利 / 成长 / 健康 / 技术

### 4.4 免责声明横幅
- 页面顶部固定浅灰蓝底 `#EEF2F6` 细横幅，13px 灰字，全文：
  "本网站内容仅供学习参考，不构成投资建议。股市有风险，投资需谨慎。"

### 4.5 公司介绍模块（个股详情页，F8）
- 位置：结论卡片之后、五组指标之前；区块标题"这家公司是做什么的？"
- 结构：一张白底卡片，内部三小段以 13px 灰色小标题分隔：
  1. **行业**：行业名 + 行业科普卡（做什么 / 怎么赚钱 / 代表产品 / 上下游链条）
  2. **这家公司**：一句话介绍 + 生活实感钩子（"你可能在哪见过它"）+ 代表产品
  3. **行业里的位置**：龙头前 3（名称 + 总市值，自动按快照总市值排名）+ 本股排名（如"行业第 2 / 全行业 40 家"）
- 样式：沿用卡片规范（白底、圆角 12px、同款阴影），纯文字排版，不引入新颜色；上下游用普通列表呈现
- 降级：行业卡缺失 → 隐藏第 1 段；个股条目缺失 → 整个模块隐藏

## 5. 页面布局规范

| 页面 | 布局 |
|---|---|
| base.html | 顶部：站名（左）+ 导航（首页/历史/方法论）+ 免责横幅 |
| 首页 | 标题"今日精选" + 推荐日期 → 3 张股票卡片横排 → 底部小字链接"为什么是这 3 只？（看筛选逻辑）" |
| 个股页 | 顶部概览条（名称/代码/现价/涨跌/行业/市值）→ 结论卡片（徽章 + 依据 + 参考价位区间 + 免责）→ 公司介绍模块（行业/公司/行业位置，§4.5）→ 五组指标网格 |
| 历史页 | 按日期倒序的日期分组列表，每只股票一行：名称、当时结论徽章、推荐日、推荐后涨跌幅（红涨绿跌，与全站"红=机会/绿=风险"语义一致） |
| 方法论页 | 文章式排版：筛选流程五步，每步一段通俗解释 + 指标名词表 |

## 6. 响应式（移动端可用）

- 断点 768px：股票卡片由横排 3 列改为纵向堆叠；指标网格由 4 列改为 2 列；导航保持单行
- 触控目标不小于 44px

## 7. 禁止事项

- ❌ 不使用图片装饰、渐变背景、大面积色块
- ❌ 不使用前端框架/CDN 外部资源（本地运行，不依赖外网）
- ❌ 不使用动画库；唯一允许的动效是卡片 hover 上浮 2px
- ❌ 不展示超过 4 种语义色同屏
