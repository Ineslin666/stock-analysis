## 1. 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 语言 | Python 3.9（venv 虚拟环境） | akshare 是 Python 库；3.9 为 macOS 自带版本 |
| 数据源 | akshare（免费接口，新浪为主 + 东财 datacenter + 巨潮个股概况） | 免费、覆盖 A 股行情与财务数据；**东财 push2 系接口在本机网络不可用**，具体接口清单见 docs_notes/01-接口实测记录.md |
| 数据处理 | pandas | 筛选、打分、分位计算 |
| 存储 | SQLite（data/stock.db） | 单文件、零配置，本地个人使用足够 |
| 后端 | FastAPI + Jinja2 服务端渲染 | 简单直接，无前后端分离负担 |
| 定时 | APScheduler | 交易日收盘后自动跑筛选 |
| 运行 | uvicorn | FastAPI 官方推荐 |

## 3. 数据流

```
akshare（东财/乐咕等免费接口）
   │  data_fetcher.py 拉取 + 本地缓存（data/ 目录，减少重复请求）
   ▼
pandas 处理 → 按 04-选股逻辑规范 逐关筛选、打分（screener.py）
   │  analyzer.py 生成买入结论与参考价位
   ▼
SQLite（推荐记录、股票数据缓存）
   │  app.py 读取
   ▼
Jinja2 渲染 → 浏览器四个页面
```

## 4. 数据更新机制

**运行模式：晨间一键运行**（按用户作息：早 8:30 开机、晚 18:30 关机，电脑无需常开后台）。

- **日常流程**：早上开机 → 终端运行 `cd ~/Desktop/模型尝试 && ./start.sh` → 脚本先执行 `scripts/daily_run.py`（① 刷新全市场快照 ② 筛选 3 只 ③ 生成结论，约 3~5 分钟，终端可见进度与最终结果）→ 自动启动网站并打开浏览器 → 浏览 http://127.0.0.1:8000 → 下班直接关机（关终端窗口即关闭网站）
- **数据口径**：晨间运行时当日 K 线尚未发布（新浪日线约 17:00~18:00 才发布当日数据，2026-08-13 实测），筛选使用最新一个收盘日的完整数据；推荐记录 rec_date 记为当天（即"今日精选"）。晚于收盘后运行（如 19:00）则当日数据已齐，自动用当日完整数据
- **兜底**：若直接以 uvicorn 启动网站（不经 start.sh），启动时检测到今天交易日且尚无当日推荐 → 后台自动补跑（约 3~5 分钟后刷新可见）
- **幂等**：同一天重复运行只覆盖不重复写入（同日推荐记录先删后插；冷却期排除当日推荐，见 04 规范 §6）
- **节假日**：非交易日运行 start.sh 会以最近交易日的完整数据幂等重跑（结果不变）

## 6. 稳定性约定

- **限流**：akshare 是网页接口封装，每只股票请求间隔 ≥ 0.15 秒，失败自动重试（3~5 次、指数退避），避免被源站封禁
- **容错**：单只股票数据缺失不中断全流程，按 04 规范 §7"数据缺失处理"执行
- **缓存**：SQLite 持久化 + 按数据更新频率设定 TTL（快照 1 天 / 财务 30 天 / 商誉 90 天 / 估值与日线增量到最近交易日），首次全量拉取约 2 小时，日常增量约 30 分钟
- **回滚**：git 管理，每个阶段完成提交一次
- **测试**：每阶段验收标准见 05-开发计划与执行步骤；数据层有 scripts/check_data.py 抽查脚本
