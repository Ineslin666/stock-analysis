# 01-需求说明

> 版本：v1.1 ｜ 2026-08-17 ｜ 状态：已定稿
> v1.1 变更：新增 F8 公司介绍模块；F5 配色描述与 03 规范 v1.1（莫兰迪色系）对齐
> 本文档定义产品要做什么、做到什么程度算合格。改动产品功能必须先改本文档。

## 1. 项目定位

面向**金融小白**的 A 股学习型网站（本地运行）。核心价值：
- 每天用一套透明、固定的逻辑筛选出 3 只优质股票，帮用户**学习**"什么算好公司、什么价位算便宜"
- 通过个股详情页教用户看懂常用财务指标
- 结论仅供学习参考，**不构成投资建议**

## 2. 功能需求与验收标准

### F1 每日推荐 3 只股票
- 每个交易日展示当天筛选出的 3 只 A 股
- 验收：交易日当天打开网站能看到 3 只；非交易日（周末/节假日）显示最近一个交易日的推荐，并标注日期

### F2 每天不重复
- 同一只股票在 60 天内不会被再次推荐（冷却期）
- 同一天推荐的 3 只股票来自不同行业
- 验收：连续查看多日推荐，60 天窗口内无重复代码，同日 3 只行业互不相同

### F3 个股详情页
点击每只股票进入详情页，展示（字段以 06-数据结构 为准）：
- 基本信息：代码、名称、行业、现价、涨跌幅、总市值
- 估值指标：PE-TTM、PB、历史分位（近 5 年）、股息率
- 盈利能力：ROE（最新年报 + 近 3 年）、毛利率、净利率
- 成长性：近 3 年营收/净利润复合增速
- 健康度：资产负债率、经营现金流净额/净利润、商誉占净资产比
- 技术面：MA20/MA60 位置关系、52 周高低点、距高点回撤
- 每个指标附**一句话通俗解释**（面向小白）
- 验收：详情页字段齐全，指标解释通俗易懂

### F4 买入结论（明确结论型）
每只股票给出明确结论，三选一：
- ✅ 值得买入
- 🟡 可以买入，建议分批
- ⚪ 暂不建议买入
附：判断依据（估值分位、技术信号）+ 参考价位区间。
**所有含结论的页面必须醒目标注"仅供学习参考，不构成投资建议"。**
- 验收：结论有明确规则依据（规则见 04-选股逻辑规范），免责声明在首页、详情页、历史页均可见

### F5 界面：清新极简
- 米白底、大量留白、莫兰迪色系点缀（雾蓝/砖红/沙金，红涨绿跌），无花哨动效
- 手机和电脑都能正常浏览
- 验收：按 03-界面设计规范 实现并通过视觉检查

### F6 历史推荐页
- 按日期倒序列出历史每日推荐，可回看、复盘
- 每只股票展示：推荐日、推荐时关键指标、当时结论、**推荐后至今涨跌幅**（复盘学习用）
- 验收：历史列表完整，涨跌幅计算正确

### F7 方法论说明页
- 用通俗语言解释筛选逻辑的每一步、每个指标的含义和阈值理由
- 验收：一个完全不懂股票的人读完后能理解"为什么选这 3 只"

### F8 公司介绍模块（2026-08-17 新增）
个股详情页新增"这家公司是做什么的？"模块，帮新手对推荐股票建立"实感"：
- **行业**：该股属于哪个行业、这个行业做什么、靠什么赚钱、代表产品、上下游链条（行业科普卡）
- **公司**：一句话通俗介绍 + 生活实感钩子（"你可能在哪见过它"）+ 代表产品
- **行业位置**：行业龙头前 3（按行业内总市值自动排名，随每日快照更新）+ 本股在行业中的排名
- **内容来源**：龙头自动计算（快照总市值）；行业卡与个股条目为人工维护知识库（knowledge/，git 跟踪），每日筛选后补写当天 3 只，60 天冷却期后复用
- 验收：模块三小段齐全、移动端正常；龙头排名与事实一致（人工抽查）；缺条目时模块优雅隐藏且每日筛选终端有提醒；知识库进 git，data/ 删除重建不影响内容

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 运行环境 | 用户自己的 Mac，浏览器访问（默认 http://127.0.0.1:8000） |
| 数据来源 | 行情与财务数据仅用 akshare 免费接口，不产生费用；公司介绍模块的行业卡/个股条目为人工维护知识库（knowledge/，git 跟踪），非外部数据源 |
| 数据更新 | 交易日收盘后（约 16:30 后）自动生成当日推荐；未运行则下次启动时补跑 |
| 网络 | 需要联网拉取行情数据；断网时页面显示缓存数据并提示 |
| 隐私 | 所有数据仅存本地，不上传任何内容 |

## 4. 免责声明（强制）

网站页面固定展示：**"本网站内容仅供学习参考，不构成投资建议。股市有风险，投资需谨慎。"**
- 首页顶部横幅 + 个股详情页结论区 + 历史页，三处必须出现。
