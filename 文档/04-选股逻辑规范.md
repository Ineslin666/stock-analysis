# 04-选股逻辑规范

> 版本：v1.3 ｜ 2026-08-26 ｜ 状态：已定稿
> v1.3 变更：§5 质量分重排——"股息回报 5 分"升级为"股东回报 10 分"（股息率 3 + 分红率 4 + 回购率 3），ROE 15→12、现金流 10→8 让分（硬门槛 §3 不变）；§8 理由"分红回报"改"股东回报"。新增字段见 06 规范 v1.2 stock_finance 表。
> 本文档是筛选引擎（screener.py）与结论引擎（analyzer.py）的唯一标准。改阈值必须先改本文档，代码与文档不一致时以本文档为准。

## 1. 总流程

```
全 A 股股票池
  → ① 基础过滤（ST/次新/停牌/低流动性）
  → ② 质量关（硬性门槛，一票否决）
  → ③ 估值关（硬性门槛，一票否决）
  → ④ 综合打分（质量 40 + 估值 40 + 技术 20 = 100 分）
  → ⑤ 排序与选择（前 3 名 + 行业分散 + 60 天冷却期）
```

## 2. ① 基础过滤（股票池规则）

剔除以下任一情况：
| 规则 | 标准 |
|---|---|
| ST/退市风险 | 名称含 "ST"、"*ST"、"退" |
| 次新股 | 上市不足 3 年（用上市日期判断，保证有足够历史财务与行情数据） |
| 停牌/异常 | 现价为 0 或缺失 |
| 低流动性 | 两步核查：① 初筛：当日成交额 < 2000 万元剔除（快照可全市场计算）；② 精确：打分前用日线计算近 20 个交易日日均成交额，< 5000 万元剔除（日线按只拉取，成本所限只对通过质量关的股票执行）。**盘中例外（2026-08-14 实测）**：盘中（9:15~15:05）当日成交额尚未累积完，开盘前后新浪快照该字段甚至全为 0，初筛会误杀全市场 → 此时跳过①，仅保留字段非空检查，流动性由②精确核查兜底（安全底线不变） |
| 行业排除 | 暂不排除任何行业，但金融地产等高杠杆行业在健康度指标上单独标注（见 §3 注 1） |

**股票池与行业口径**：股票池 = 沪主板 + 科创板 + 深市主板/创业板（约 5200 只，北交所数据覆盖不全不纳入）。行业取新浪行业分类（49 类）优先，新浪未覆盖的股票用巨潮个股概况的"所属行业"（证监会 2012 大类）补齐。

## 3. ② 质量关（全部满足才通过）

| 指标 | 阈值 | 说明 |
|---|---|---|
| ROE（最新年报） | ≥ 12% | 净资产收益率，衡量赚钱能力 |
| ROE（近 3 年每年） | 均 ≥ 10% | 盈利的持续性 |
| 营收增速（近 3 年复合） | > 0% | 不能萎缩；注 2：金融业无营收增速数据时以净利润增速替代核查 |
| 净利润增速（近 3 年复合） | > 0% | 利润同步增长 |
| 资产负债率 | < 60% | 注 1：银行/保险/地产等天然高杠杆行业放宽到 < 85%，页面单独标注"高杠杆行业" |
| 经营现金流净额 / 净利润（最新年报） | ≥ 0.7 | 利润是真金白银，不是纸面数字；注 3：金融业（银行/保险/证券）不适用本指标，直接通过并在页面标注 |
| 股息率（近 12 个月） | > 0 | 有分红习惯，愿意回报股东；注 4：股息率按"近 12 个月已实施派息合计÷10÷现价"计算（新浪派息数据为每 10 股口径），只对通过其余质量指标的候选拉取 |

注 5：营收/净利润"近 3 年复合增速"用最近 3 个年报的同比增速几何平均近似（新浪财务接口无营收绝对值序列）。

## 4. ③ 估值关（全部满足才通过）

| 指标 | 阈值 |
|---|---|
| PE-TTM | > 0（剔除亏损）且 < 50 |
| PE-TTM 近 5 年历史分位 | < 50% |
| PB 近 5 年历史分位 | < 70% |

分位计算方法：取近 5 年（约 1200 个交易日）每日 PE/PB，当前值在其中的百分位。历史序列不足 3 年的按可用长度计算。

## 5. ④ 综合打分（满分 100）

### 质量 40 分
| 子项 | 满分 | 打分规则 |
|---|---|---|
| ROE 水平 | 12 | 最新年报 ROE：12%~15% 得 6；15%~20% 得 9；>20% 得 12 |
| 成长性 | 10 | 营收复合增速：0~10% 得 2、10~20% 得 4、>20% 得 5；净利润复合增速同档另计（两者相加满分 10） |
| 现金流质量 | 8 | 经营现金流/净利润：0.7~1.0 得 5；≥1.0 得 8 |
| 股东回报 | 10 | 股息率（满分 3）：0~1% 得 1、1~2% 得 2、>2% 得 3；分红率（满分 4）：<30% 得 1、30~50% 得 2、50~70% 得 3、>70% 得 4；回购率（满分 3）：无回购得 0、>0 得 1、>10% 得 2、>20% 得 3。三项相加满分 10。分红率/回购率缺失时该项计 0 分不剔除 |

### 估值 40 分（PE-TTM 近 5 年分位越低分越高）
| 分位区间 | 得分 |
|---|---|
| < 20% | 40 |
| 20%~35% | 30 |
| 35%~50% | 20 |
| 50%~70% | 10 |
| ≥ 70% | 0 |

### 技术 20 分
| 子项 | 得分 |
|---|---|
| 收盘价 > MA60（60 日均线） | +8 |
| 收盘价 > MA20 | +6 |
| 距 52 周最高点回撤 < 20% | +6 |

## 6. ⑤ 排序与选择

1. 按总分降序排列
2. **行业分散**：从高分到低分依次选取，同一行业（按行业名精确匹配）每天最多 1 只，已满则跳过取下一名
3. **60 天冷却期**：查询推荐记录表，过去 60 个自然日内已推荐过的代码直接剔除出候选池。**例外**：重跑同一交易日（幂等覆盖，如定时任务覆盖当日盘中补跑）时，当日已有的推荐不计入冷却名单，保证同样的数据重跑仍选出真正的 Top 3
4. 取最终前 3 名。若合格候选不足 3 只，有多少展示多少，并在页面上标注"今日符合标准的股票不足 3 只"

## 7. 数据缺失处理

| 情况 | 处理 |
|---|---|
| 关键指标缺失（ROE、PE-TTM、营收、净利） | 直接剔除该股，不计入候选 |
| 次要指标缺失（股息率、分红率、回购率、现金流、商誉等） | 该子项计 0 分，不剔除（金融业现金流指标按 §3 注 3 处理） |
| 无法计算历史分位（次新剔除后仍不足 3 年数据） | 估值子项计 10 分（中性），页面标注"历史数据不足" |
| 日线/估值历史接口暂时失败 | 技术子项计 0 分；但 20 日成交额无法核查时不进入最终推荐（流动性是安全底线） |

## 8. 输出格式

每只推荐股票输出（写入数据库 + 页面展示）：
- 代码、名称、行业、总分
- 筛选理由：**面向金融小白的通俗语言**，每条 = "指标是什么 + 本公司数值 + 为什么好"，不得使用不加解释的专业术语。
  示例："赚钱能力：ROE 27.1%——股东每投 100 元，公司一年能赚 27.1 元，连续 3 年都高于 10% 的及格线"。
  固定包含 8 条：赚钱能力（ROE）、成长性（营收/净利复合增速）、财务安全（资产负债率）、利润含金量（现金流/净利）、股东回报（股息率+分红率+回购）、估值便宜（PE-TTM + 5 年分位）、买卖方便（20 日均成交额）、综合得分（质量/估值/技术三块拆解 + 技术面通俗说明）
- 买入结论与参考价位（生成规则见 §9）

## 9. 买入结论规则（analyzer.py 的唯一标准）

### 9.1 结论判定（输入：PE 分位 + 技术分，两者由筛选阶段的同一数据源复算）

| 条件 | 结论 | verdict |
|---|---|---|
| PE 分位 < 30% 且 技术分 ≥ 14 | **值得买入**：估值处于历史低位，走势健康 | `buy` |
| PE 分位 30%~50% 且 技术分 ≥ 14 | **建议分批买入**：估值不算贵，可先建仓分批介入 | `buy_batch` |
| PE 分位 < 50% 且 技术分 8~13 | **建议分批买入**：估值便宜但走势一般，分批更稳妥 | `buy_batch` |
| PE 分位 ≥ 50% | **暂不建议买入**：估值高于历史中位数，等待更好价格 | `hold` |
| 技术分 < 8 | **暂不建议买入**：走势偏弱（跌破均线或回撤过深），不接下跌趋势 | `hold` |
| PE 分位不可算（历史数据不足） | 保守处理：技术分 ≥ 14 → `buy_batch`（估值无法确认便宜，降级为分批）；否则 `hold`。页面标注"历史数据不足" | — |

注 6：技术分 = 收盘价>MA60(+8) + 收盘价>MA20(+6) + 距 52 周高点回撤<20%(+6)，与 §5 打分口径一致，由日线数据复算。

### 9.2 参考价位（四舍五入到 0.01 元，前复权口径）

1. **均线区间**（主参考）：`ref_price_low = min(MA20, MA60)`，`ref_price_high = max(MA20, MA60)`
2. **估值参考价**（PE 分位可算时给出）：`pe30 价 = 近 5 年 PE 序列第 30 百分位值 ÷ 当前 PE-TTM × 当日收盘价`。含义：股价回到"历史 PE 分位 30%"水平对应的价格。
3. 现价位于均线区间内或下方 → 结论文本注明"当前价已处于参考区间"；现价高于区间上沿 → 注明"建议等待回调至区间内"。

### 9.3 结论文本

- 每条结论必须包含：结论标签（如上表）、一句理由（引用 PE 分位/技术信号的具体数值）、参考价位区间、**免责声明："仅供学习参考，不构成投资建议。股市有风险，投资需谨慎。"**
- 写入 recommendations 表的 `verdict`、`verdict_reason`（结论+理由+价位全文）、`ref_price_low`、`ref_price_high` 四列。
