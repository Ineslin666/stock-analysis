# 04-选股逻辑规范

> 版本：v1.0 ｜ 2026-08-13 ｜ 状态：已定稿
> 本文档是筛选引擎（screener.py）的唯一标准。改阈值必须先改本文档，代码与文档不一致时以本文档为准。

## 1. 总流程

```
全 A 股股票池
  → ① 基础过滤（ST/次新/停牌/低流动性）
  → ② 质量关（硬性门槛，一票否决）
  → ③ 估值关（硬性门槛，一票否决）
  → ④ 综合打分（质量 40 + 估值 40 + 技术 20 = 100 分）
  → ⑤ 排序与选择（前 3 名 + 行业分散 + 60 天冷却期）
```

## 2. ① 基础过滤（股票池规则）

剔除以下任一情况：
| 规则 | 标准 |
|---|---|
| ST/退市风险 | 名称含 "ST"、"*ST"、"退" |
| 次新股 | 上市不足 3 年（用上市日期判断，保证有足够历史财务与行情数据） |
| 停牌/异常 | 现价为 0 或缺失 |
| 低流动性 | 日均成交额 < 5000 万元（近 20 个交易日） |
| 行业排除 | 暂不排除任何行业，但金融地产等高杠杆行业在健康度指标上单独标注（见 §3 注 1） |

## 3. ② 质量关（全部满足才通过）

| 指标 | 阈值 | 说明 |
|---|---|---|
| ROE（最新年报） | ≥ 12% | 净资产收益率，衡量赚钱能力 |
| ROE（近 3 年每年） | 均 ≥ 10% | 盈利的持续性 |
| 营收增速（近 3 年复合） | > 0% | 不能萎缩 |
| 净利润增速（近 3 年复合） | > 0% | 利润同步增长 |
| 资产负债率 | < 60% | 注 1：银行/保险/地产等天然高杠杆行业放宽到 < 85%，页面单独标注"高杠杆行业" |
| 经营现金流净额 / 净利润（最新年报） | ≥ 0.7 | 利润是真金白银，不是纸面数字 |
| 股息率（近 12 个月） | > 0 | 有分红习惯，愿意回报股东 |

## 4. ③ 估值关（全部满足才通过）

| 指标 | 阈值 |
|---|---|
| PE-TTM | > 0（剔除亏损）且 < 50 |
| PE-TTM 近 5 年历史分位 | < 50% |
| PB 近 5 年历史分位 | < 70% |

分位计算方法：取近 5 年（约 1200 个交易日）每日 PE/PB，当前值在其中的百分位。历史序列不足 3 年的按可用长度计算。

## 5. ④ 综合打分（满分 100）

### 质量 40 分
| 子项 | 满分 | 打分规则 |
|---|---|---|
| ROE 水平 | 15 | 最新年报 ROE：12%~15% 得 8；15%~20% 得 12；>20% 得 15 |
| 成长性 | 10 | 营收复合增速：0~10% 得 2、10~20% 得 4、>20% 得 5；净利润复合增速同档另计（两者相加满分 10） |
| 现金流质量 | 10 | 经营现金流/净利润：0.7~1.0 得 6；≥1.0 得 10 |
| 股息回报 | 5 | 股息率：0~1% 得 1；1%~2% 得 3；>2% 得 5 |

### 估值 40 分（PE-TTM 近 5 年分位越低分越高）
| 分位区间 | 得分 |
|---|---|
| < 20% | 40 |
| 20%~35% | 30 |
| 35%~50% | 20 |
| 50%~70% | 10 |
| ≥ 70% | 0 |

### 技术 20 分
| 子项 | 得分 |
|---|---|
| 收盘价 > MA60（60 日均线） | +8 |
| 收盘价 > MA20 | +6 |
| 距 52 周最高点回撤 < 20% | +6 |

## 6. ⑤ 排序与选择

1. 按总分降序排列
2. **行业分散**：从高分到低分依次选取，同一行业（按行业名精确匹配）每天最多 1 只，已满则跳过取下一名
3. **60 天冷却期**：查询推荐记录表，过去 60 个自然日内已推荐过的代码直接剔除出候选池
4. 取最终前 3 名。若合格候选不足 3 只，有多少展示多少，并在页面上标注"今日符合标准的股票不足 3 只"

## 7. 数据缺失处理

| 情况 | 处理 |
|---|---|
| 关键指标缺失（ROE、PE-TTM、营收、净利） | 直接剔除该股，不计入候选 |
| 次要指标缺失（股息率、现金流等） | 该子项计 0 分，不剔除 |
| 无法计算历史分位（次新剔除后仍不足 3 年数据） | 估值子项计 10 分（中性），页面标注"历史数据不足" |

## 8. 输出格式

每只推荐股票输出（写入数据库 + 页面展示）：
- 代码、名称、行业、总分
- 筛选理由：逐条列出通过的关键门槛（如"ROE 连续 3 年 > 10%，最新 16.8%"）+ 得分亮点
- 买入结论与参考价位（生成规则见 analyzer.py 设计，随阶段 3 补充进本规范 §9）
