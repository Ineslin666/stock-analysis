# 06-数据结构与数据字典

> 版本：v1.1 ｜ 2026-08-17 ｜ 状态：已定稿
> v1.1 变更：stock_snapshot.total_mv 来源改为新浪行业板块成分（mktcap 万元→元）写入约 3000 只（行业龙头排名用，F8）；候选股仍由 stock_value_em 权威值覆盖。
> SQLite 数据库 `data/stock.db` 的表结构定义。改表结构必须先改本文档。

## 1. 通用约定

- 数据库文件：`data/stock.db`（git 忽略，可删除重建）
- 股票代码统一存**纯数字字符串**（如 `"600519"`）
- 日期统一 `YYYY-MM-DD` 字符串
- 所有表通过 db.py 读写，页面层不直接操作数据库

## 2. 表定义

### 2.1 recommendations —— 每日推荐记录（核心表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | 自增 |
| rec_date | TEXT | 推荐日期（交易日），`YYYY-MM-DD` |
| code | TEXT | 股票代码 |
| name | TEXT | 股票名称 |
| industry | TEXT | 行业 |
| rank | INTEGER | 当日名次 1/2/3 |
| score | REAL | 综合得分（满分 100） |
| reasons | TEXT | 筛选理由，多行文本 |
| verdict | TEXT | 结论：`buy`（值得买入）/ `buy_batch`（建议分批）/ `hold`（暂不建议），由 analyzer.py 生成（规则见 04 规范 §9） |
| verdict_reason | TEXT | 结论全文：结论标签 + 理由（引用 PE 分位/技术信号数值）+ 参考价位 + 免责声明 |
| ref_price_low | REAL | 参考价位下限（min(MA20, MA60)，0.01 元精度） |
| ref_price_high | REAL | 参考价位上限（max(MA20, MA60)，0.01 元精度） |
| close_price | REAL | 推荐日收盘价 |
| pe_ttm | REAL | 推荐日 PE-TTM |
| pe_percentile | REAL | 推荐日 PE 近 5 年分位（%） |
| roe | REAL | 推荐日最新年报 ROE（%） |
| dividend_yield | REAL | 推荐日股息率（%） |
| created_at | TEXT | 记录写入时间 |

- 唯一约束：`(rec_date, code)`
- 索引：`rec_date`、`code`（冷却期查询）
- 写入规则：同一天重复运行 = 先删当日记录再插入（幂等）

### 2.2 stock_snapshot —— 全市场快照缓存

| 字段 | 类型 | 说明 |
|---|---|---|
| code | TEXT PK | 股票代码 |
| name | TEXT | 名称 |
| industry | TEXT | 行业（新浪行业优先，缺者用巨潮个股概况补齐；见 04 规范 §2） |
| list_date | TEXT | 上市日期 |
| price | REAL | 最新价（新浪全市场快照） |
| pe_ttm | REAL | 市盈率 TTM（候选股由 stock_value_em 回填，权威值；非候选可能为空） |
| pb | REAL | 市净率（同上） |
| total_mv | REAL | 总市值（元）：新浪行业板块成分（mktcap 万元→元）写入约 3000 只（行业龙头排名用，F8）；候选股由 stock_value_em 回填权威值覆盖 |
| turnover_today | REAL | 当日成交额（元，新浪全市场快照） |
| turnover_avg20 | REAL | 近 20 日日均成交额（元，打分阶段回填） |
| dividend_yield | REAL | 股息率（%）= 近12月已实施派息合计÷10÷现价×100 |
| div_updated_at | TEXT | 股息率数据更新时间（缓存 TTL 30 天依据） |
| updated_at | TEXT | 快照更新时间 |

写入规则：**列级合并**（传入 NULL 不覆盖已有值），避免列表/快照/行业三个来源互相覆盖。

### 2.3 stock_finance —— 财务指标缓存（每只股票一行，最新年报为主）

| 字段 | 类型 | 说明 |
|---|---|---|
| code | TEXT PK | 股票代码 |
| roe_latest | REAL | 最新年报 ROE（%） |
| roe_3y_json | TEXT | 近 3 年各年 ROE，JSON 数组 |
| revenue_cagr3 | REAL | 近 3 年营收复合增速（%） |
| profit_cagr3 | REAL | 近 3 年净利润复合增速（%） |
| debt_ratio | REAL | 资产负债率（%） |
| ocf_to_profit | REAL | 经营现金流净额/净利润 |
| gross_margin | REAL | 毛利率（%） |
| net_margin | REAL | 净利率（%） |
| goodwill_ratio | REAL | 商誉/归母股东权益（%），由 fetch_goodwill_ratio 单独维护 |
| goodwill_updated_at | TEXT | 商誉数据更新时间（缓存 TTL 90 天依据） |
| updated_at | TEXT | 财务指标更新时间 |

写入规则：upsert 不覆盖 goodwill 两列（财务与商誉分属不同数据源，独立更新）。

### 2.4 stock_daily —— 日线行情缓存（分位/均线/回撤计算用）

| 字段 | 类型 | 说明 |
|---|---|---|
| code | TEXT | 股票代码 |
| trade_date | TEXT | 交易日 `YYYY-MM-DD` |
| close | REAL | 收盘价 |
| pe | REAL | 当日 PE（分位计算用，可空） |
| pb | REAL | 当日 PB（可空） |
| turnover | REAL | 成交额（元） |

- 主键：`(code, trade_date)`；**按源分写**：close/turnover 来自新浪日线 stock_zh_a_daily（前复权），pe/pb 来自 stock_value_em，各自 ON CONFLICT 更新自己的列，互不覆盖
- close 为前复权价（均线/回撤计算口径一致）；增量更新到最近交易日

### 2.5 screening_log —— 筛选运行日志（调试与复盘）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | 自增 |
| run_date | TEXT | 运行日期 |
| run_time | TEXT | 运行时刻 |
| pool_size | INTEGER | 基础股票池数量 |
| passed_quality | INTEGER | 质量关通过数 |
| passed_valuation | INTEGER | 估值关通过数 |
| candidates_json | TEXT | 最终候选（代码+得分），JSON |
| status | TEXT | `ok` / `error` / `partial` |
| error_msg | TEXT | 失败原因 |

### 2.6 trade_calendar —— 交易日历缓存

| 字段 | 类型 | 说明 |
|---|---|---|
| cal_date | TEXT PK | 日期 `YYYY-MM-DD` |
| is_open | INTEGER | 1=交易日 0=非交易日 |

## 3. 分位计算约定

- PE/PB 近 5 年分位：取 stock_daily 中该股最近 5 年（不足 3 年按实际）的每日 PE/PB，当前值在序列中的百分位 = `(小于当前值的个数) / 总个数 × 100`
- 无效值（≤0 或缺失）不参与序列
